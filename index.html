What this book is

A chapter-based, hands-on path from an empty directory to a C++ test suite that mocks its dependencies, runs clean under sanitizers, and executes in CI. You build each example locally on Fedora 44 with Clang, CMake, Conan, and GoogleTest and GoogleMock, run it under ASan, UBSan, and ThreadSanitizer, and measure what the suite exercises with llvm-cov. It assumes you can already build a C++ project; this is not a C++ language tutorial. Everything runs locally, with no containers and no VM.
